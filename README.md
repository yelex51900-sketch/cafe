# 喫茶室 moku — ポートフォリオ用サイト

静かな和モダンの雰囲気を意識した、レスポンシブな喫茶店ホームページです。

## ページ構成
- `index.html` — トップ、季節のおすすめ
- `menu.html` — メニュー（トップからのアンカーリンクあり）
- `concept.html` — コンセプト
- `access.html` — 店舗情報・地図リンク
- `reservation.html` — 入力検証付きのデモ予約フォーム
- `assets/style.css` — 共通デザイン、スマートフォン対応
- `assets/script.js` — モバイルメニュー、予約フォーム処理

## 確認方法
`index.html` をブラウザで開いてください。サーバーを使わずに閲覧できます。GitHub Pages に公開する場合は、ファイル一式をリポジトリのルートに配置してください。

## 注意
店舗名・住所・営業時間・価格は架空のポートフォリオ用設定です。予約フォームはフロントエンドのデモで、送信・保存・メール送信は行いません。写真とGoogle Fontsは外部配信のため、画像・フォントの表示にはインターネット接続が必要です。実案件で使用する場合は、写真の利用条件、実店舗情報、予約のバックエンドを確認・差し替えてください。
